# RedBreacher

탱크로 끝없이 몰려오는 적들을 물리치고, 성장하고, 기지를 업그레이드하여 보스를 물리처 성장하는 2.5D 탑다운 시점으로한 방치형 SF밀리터리풍 슈팅게임입니다.
이 프로젝트는 3인 개발팀으로부터 개발을 진행했으며, 저는 <b>각종 UI 애니메이션, 설정 메뉴, 기지 디자인 등 인게임 디자인/UI 구현</b>에 담당했습니다.
